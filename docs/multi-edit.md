# 批量编辑手册

> 配置在 `modules/use-multi-edit.el`：`iedit`(MELPA) 管“同一个词到处改”，
> Emacs 内置的 `occur-edit-mode` 管“每行改成不同内容”。

## 1. 三个入口

| 键        | 命令                          | 用途                         |
| --------- | ----------------------------- | ---------------------------- |
| `C-c s`   | `iedit-mode`                  | 全 buffer 统一替换同一个词   |
| `C-0 C-c s` | `iedit-mode`(前缀 0)        | 只在**当前函数**内统一替换   |
| `C-c e`   | `my/occur-edit-symbol`        | 列出匹配行，**逐行**改，可每行不同 |

先选路：

- 所有出现处都换成**同一个新串** → `C-c s`（需要限定范围就加 `C-0` / `M-H` / `M-I`）；
- 每处要换成**不同的内容**，或要重写整行 → `C-c e`；
- 只是想给每行加同样的东西（行尾逗号、行首 `- `）→ 两者都不合适，用矩形或宏，见第 7 节。

## 2. iedit 基本用法

```text
1. 光标停在 old_name 上（不要有选区）   → C-c s
2. 回显 "6 matches for \"old_name\""，模式行出现  Iedit:1/6
3. M-d 删掉光标处的词，输入新名字
4. 再按 C-c s 退出
```

要点：

- 改的是**整段 occurrence 的新内容**，其余位置同步；大小写模式会保留
  （`getFoo`/`getfoo`/`GETFOO` 改成 `getBar` 后分别变 `getBar`/`getbar`/`GETBAR`）；
- 输入时当前这一处有短暂缓冲，继续操作（移动光标/再按键）时才同步到其他处；
- 改错直接 `C-/`，批量改动正常进 undo 历史（也是 undo-tree 的节点）。

## 3. 限定范围

| 想限定到           | 做法                                                       |
| ------------------ | ---------------------------------------------------------- |
| 当前函数           | `C-0 C-c s`，或先 `C-c s` 再 `M-H`                          |
| 当前行             | 先 `C-c s` 再 `M-I`                                         |
| 选中的代码块       | 先 `C-c s` 开启，**再**拉选区，**再**按一次 `C-c s`          |
| 块边界不好选       | `C-x n n` 缩窄到块 → `C-c s` → 改完 `C-x n w`               |
| 排除个别位置       | `C-c s` 后 `M-;` 逐处剔除                                   |

**顺序陷阱**：有选区时按 `C-c s`，iedit 会把「选中的整段文本」当成匹配串，并且
立刻清掉选区；此时再按一次就等于关闭。所以必须“先开启 → 再选 → 再按”。
实测 4 处 → 选中其中 2 处 → 再按 → 只剩 2 处，区域外不参与。

## 4. iedit 内部键位

| 键            | 作用                                  |
| ------------- | ------------------------------------- |
| `C-c s`       | 开启/关闭                             |
| `M-I`         | 限制在当前行                          |
| `M-H`         | 限制在当前函数                        |
| `M-{` / `M-}` | 搜索范围向上/向下扩一行               |
| `M-n` / `M-p` | 范围扩到下一个/上一个出现处           |
| `M-;`         | 选中/取消光标下这一处（跳过不改）     |
| `M-C`         | 切换大小写敏感                        |
| `M-S`         | 切换是否搜不可见文本                  |

## 5. 从 isearch 进入

```text
C-s old_name        （或 C-M-s 用正则）
C-c s               → 以搜索串进入 iedit
```

这条路用你打进去的字符串做字面匹配，**绕开 `thing-at-point` 的词边界**，也能在
`sh-mode` 这类 `.` 算符号的模式里精确匹配 `old_name.x` 中的 `old_name`。

限制：**所有匹配长度必须一致**，否则 iedit 报 `Matches are not the same length.`
并退出。

## 6. occur-edit（`C-c e`）

```text
1. 光标停在符号上      → C-c e
2. 弹出 *Occur*，模式行 Occur-Edit，已进入可编辑状态
3. 逐行改成需要的内容（每行可以不一样）
4. C-c C-c 退出编辑态；再按 e 可重新进入，q 关掉窗口
```

要点：

- **实时联动**：改一行，源文件对应行立刻变（`after-change-functions`），
  不存在“最后统一提交”这一步，`C-c C-c` 只是退出编辑态；
- **不能新增行**：插进去的换行会被丢弃，条目和源文件行是一对一的；
- 行首的 `1:` 前缀是 `read-only` 文本属性，光标放不进去、也改不了；
- 源 buffer 只读时只提示 `Buffer ... is read only.`，不会修改；
- 每次 `occur` 复用同一个 `*Occur*` buffer，旧内容被覆盖。

**不要**在 `*Occur*` 里再开 iedit：那会是“iedit 在渲染层同步 → occur-edit 再写回
源文件”的两层链路，比直接在源 buffer 里 `C-c s` 更慢更易错。

## 7. 与其他内置手段的分工

| 需求                         | 用什么                                        |
| ---------------------------- | --------------------------------------------- |
| 同一词统一替换               | `C-c s`（本模块）                             |
| 每行改成不同内容             | `C-c e`（本模块）                             |
| 矩形区域插/删同一段文字      | `C-x SPC` 选矩形 → `C-x r t` / `C-x r k`      |
| 每行套用同一个操作           | 录宏 `F3` → 选中多行 → `C-x C-k r`            |
| 跨文件批量替换               | `C-x p r`（`project-query-replace-regexp`）   |

## 8. 常见问题速查

| 现象                                         | 原因 / 解决                                                      |
| -------------------------------------------- | ---------------------------------------------------------------- |
| 按 `C-c s` 只匹配到 1 处                     | 带了前缀（`C-u`/`C-1`），或 `sh-mode` 里 `.` 被算进符号           |
| `old_name.x` 里匹配不到 `old_name`           | `.` 在该模式语法表里是符号字符；用 `C-s old_name` → `C-c s`      |
| 第二次按 `C-c s` 直接退出                    | 选区在第一次按的时候已被清掉；顺序应为 开启 → 选 → 再按           |
| `C-0 C-c s` 没反应                           | 终端送不出 `Ctrl+0`；GUI 下正常，终端里改用 `C-c s` + `M-H`       |
| `Matches are not the same length.`           | 正则匹配长度不一致；改用长度一致的模式或分批处理                  |
| `*Occur*` 里按回车/粘贴换行无效              | occur 条目不能新增，换行会被丢弃                                  |
| `*Occur*` 里改不动行首 `1:`                  | 那是只读前缀，本来就不能改                                        |

## 9. 一页速记

```text
统一替换: C-c s          限定函数: C-0 C-c s（或 C-c s + M-H）
限定本行: M-I            跳过某处: M-;
选块限定: C-c s → 选块 → C-c s     缩窄: C-x n n → C-c s → C-x n w
正则入口: C-M-s 正则 RET → C-c s   （匹配长度须一致）
逐行不同: C-c e → 改 → C-c C-c 退出（改动实时写回）
矩形/宏: C-x SPC + C-x r t        F3 录制 + C-x C-k r
```
