* Emacs 新手教程
这是一份写给第一次接触 Emacs 的你。教程最好的读法是 *边读边动手*:

- 行首的 =>>= 表示"请你现在动手试一试";
- 这份文件是你自己的副本,随便改,改坏了也不影响母本;
- 任何时候感觉不对劲,先按 =C-g= (后面马上讲到)。

--------------

** 先看懂两个记号
Emacs 的命令离不开两个修饰键,教程里用简写表示:

| 记号 | 意思       | 怎么按                                         |
|------+------------+------------------------------------------------|
| =C-= | CONTROL 键 | 按住 CONTROL(通常标着 *Ctrl*),再按后面那个字符 |
| =M-= | META 键    | 按住 META(通常标着 *Alt*),再按后面那个字符     |

举例:

- =C-f= = 按住 Ctrl 不放然后按一下 =f=
- =M-v= = 按住 Alt 不放然后按一下 =v=

*这两个重要快捷键先记住:*

| 按键       | 作用                   |
|-----------+-----------------------|
| =C-g=     | 万能取消: 命令卡住｜输错了 |
| =C-x C-c= | 退出 Emacs             |


#+begin_quote
💡 少数命令默认是"禁用"的(防止误触)输入后 Emacs 会说明并询问你:按 *空格* = 照常执行,按 =n= = 放弃。

#+end_quote

#+begin_quote

#+begin_quote
输入 =C-x C-l= (一个被禁用的命令),看看提示,然后按 =n= 拒绝。

#+end_quote

#+end_quote

一屏一屏地看长文档:

| 按键  | 作用                                                          |
|-------+---------------------------------------------------------------|
| =C-v= | 向下翻一屏                                                    |
| =M-v= | 向上翻一屏                                                    |
| =C-l= | 刷新屏幕,把光标所在行挪到屏幕中间(连按会在顶部/中间/底部轮换) |

键盘上的 PageUp / PageDn 键也能翻,但 =C-v= 、 =M-v= 手不离位,更快。

#+begin_quote
按 =C-v= 翻到下一屏,再按 =M-v= 翻回来,多试几次。以后读到屏幕底部就按 =C-v= 继续往下。

#+end_quote

#+end_quote

** 移动光标
把光标想象成你在文本里的"位置"。方向键也能用,但下面这组更快(手不用离开打字区):

|            | =C-p= 上一行 ↑ |            |
| =C-b= 左 ← | 光标           | → =C-f= 右 |
|            | ↓ =C-n= 下一行 |            |

#+begin_quote
💡 记法:四个字母都是缩写 ------ *P* revious(上)、 *N* ext(下)、 *B* ackward(左)、 *F* orward(右)。

#+end_quote

| 按键          | 移动到               |
|---------------+----------------------|
| =C-f= / =C-b= | 后一个 / 前一个字符  |
| =C-n= / =C-p= | 下一行 / 上一行      |
| =M-f= / =M-b= | 后一个 / 前一个 *词* |
| =C-a= / =C-e= | 行首 / 行尾          |
| =M-a= / =M-e= | 句首 / 句尾          |
| =M-<=         | 整个文件的开头       |
| =M->=         | 整个文件的末尾       |

#+begin_quote
💡 发现规律了吗? *C 键管"小单位"(字符、行),M 键管"大单位"(词、句、整个文件)* 。Emacs 里到处都是这个规律。

#+end_quote

#+begin_quote

#+begin_quote
把上面的键每个都按几下,找找感觉。行首按 =C-b= 会跳到上一行末尾 ------ 它跨过了换行符, =C-f= 同理。

#+end_quote

#+end_quote

*重复 N 次*:先按 =C-u=,再输数字,最后按命令。

- =C-u 8 C-f= = 向右移动 8 个字符;
- 有 Alt 键的话,按住 Alt 直接敲数字也行;
- =C-u 8 C-v= 是个特例:向下滚动 8 *行* (而不是 8 屏)。

#+begin_quote

#+begin_quote
用 =C-u 8 C-v= 和 =C-u 8 M-v= 滚动试试。

#+end_quote

#+end_quote

** 输入
*输入最简单:直接打字就行。* 想换行就按 *回车* (=<Return>= 键)。回车有时还会自动补上空格,让新行和上一行对齐,这叫"电动"行为,不用管它。

一行太长放不下时,Emacs 会自动"续行"显示,内容并没有断。

#+begin_quote
试试连续打字到行尾,看续行出现;再按 =C-u 8 *=,一次插入八个星号。

#+end_quote

** 删除
| 按键                       | 删除什么                                            |
|----------------------------+-----------------------------------------------------|
| =<DEL>= (就是 *Backspace*) | 光标 *前面* 的一个字符                              |
| =C-d=                      | 光标 *后面* 的一个字符                              |
| =M-<DEL>=                  | 光标前面的一个词                                    |
| =M-d=                      | 光标后面的一个词                                    |
| =C-k=                      | 从光标删到 *行尾* (再按一次,整行连同换行符一起删掉) |
| =M-k=                      | 从光标删到 *句尾*                                   |

#+begin_quote
💡 红线区:本文说的 =<DEL>= 是 *Backspace 键* 。键盘上另一个标着 "Delete" 的键 *不是* 它,别搞混。

#+end_quote

*删除一大段* (三步走):

1. 移到段落开头,按 =C-<SPC>= (按住 Ctrl 敲空格),底部会提示 "Mark set"(已设标记);
2. 移到段落末尾,途中 Emacs 会高亮你要删的部分;
3. 按 =C-w= ------ 高亮的内容整段删除。

#+begin_quote

#+begin_quote
输入几个字符再用 =<DEL>= 删掉;再找一段文字,用三步把它整段删掉。

#+end_quote

#+end_quote

** 撤销:改错了不要慌
刚删的、刚改的,都能撤回来:

| 按键                        | 作用                           |
|-----------------------------+--------------------------------|
| =C-/= (或 =C-_= 、 =C-x u=) | 撤销上一步; *连按就一直往回撤* |

- 打错一大串字?别一个个删,直接 =C-/=,整串消失;
- =C-g= 取消不了撤销,想停就别按了;
- 撤销多了想"反悔"?原教程的建议是:一路 =C-/= 撤到底再重新来。

#+begin_quote

#+begin_quote
用 =C-k= 删掉这一行,再按 =C-/=,看它回来。

#+end_quote

#+end_quote

** 剪切、复制、粘贴
第 5 节那些 =C-k= 、 =C-w= 删掉的内容其实 *没有丢* ------ 它们被"剪切"进了剪贴板。Emacs 术语不同,但道理一样:

| 日常说法   | Emacs 术语         | Emacs 操作        |
|------------+--------------------+-------------------|
| 剪切       | kill               | =C-k= 、 =C-w= 等 |
| 粘贴       | yank               | =C-y=             |
| 剪贴板历史 | kill ring(可以翻!) | =M-y=             |

*粘贴*: =C-y=,把最近剪切的内容插回光标处。连续几次 =C-k= 的内容会攒在一起,一次 =C-y= 全部回来。

*复制*:剪切(=C-w=)后按 =C-/= 撤销删除,再找个地方 =C-y= 粘贴 ------ 内容就复制过去了。

*翻剪贴板历史*:刚 =C-y= 粘贴完,按 =M-y= 会替换成上一次剪切的内容;连按往更早翻,翻过头了会绕回来。

#+begin_quote

#+begin_quote
剪切一行(=C-k=),移动几行,按 =C-y= 粘贴;再按 =M-y= 看看换成了什么。重复几次,感受"剪贴板历史"。

#+end_quote

#+end_quote

** 文件操作:打开、保存、自动备份
你正在编辑的内容默认只在内存里, *不保存,退出就没了* 。

| 按键      | 作用                                                  |
|-----------+-------------------------------------------------------|
| =C-x C-f= | 打开文件(想 *新建* 文件,直接输一个不存在的文件名即可) |
| =C-x C-s= | 保存当前文件                                          |
| =C-x s=   | 逐个询问,把所有改过的文件都保存一遍                   |

#+begin_quote
💡 输入文件名时,Emacs 底部会弹出一行让你打字,这叫 *minibuffer* 。中途想反悔,按 =C-g= 取消;打完按回车确认。

#+end_quote

#+begin_quote
💡 第一次保存时,Emacs 会把旧文件备份成 =文件名~=,改坏了还能找回来。

#+end_quote

#+begin_quote
💡 Emacs 还会 *定期自动保存*,存成 =#test.txt#= 这样的名字(正常保存后它会被删掉)。万一电脑崩溃,重新 =C-x C-f= 打开原文件,再执行 =M-x recover-this-file <Return>= 、回答 =yes=,崩溃前的内容就找回来了。

#+end_quote

#+begin_quote

#+begin_quote
按 =C-x C-f=,随便输个文件名(比如 =test.txt=),回车。新文件建好了,随手打几个字,按 =C-x C-s= 保存,看底部显示 "Wrote ..."。

#+end_quote

#+end_quote

** 缓冲区(buffer)
*缓冲区 = 文件在 Emacs 内部的样子* 。你打开 =a.txt=,Emacs 就建一个叫 =a.txt= 的缓冲区。你看到的任何文字,都属于某个缓冲区。

| 按键      | 作用                                                 |
|-----------+------------------------------------------------------|
| =C-x C-b= | 列出所有缓冲区                                       |
| =C-x b=   | 按名字切换缓冲区(切换回去也就是"重新打开"了那个文件) |

#+begin_quote
💡 有些缓冲区不对应任何文件,比如放系统消息的 =*Messages*=,还有 =C-x C-b= 列出来的 =*Buffer List*= (看完按 =C-x 1= 关掉)。

#+end_quote

#+begin_quote

#+begin_quote
按 =C-x C-b= 看列表;再按 =C-x b *Messages* <Return>= 看看消息缓冲区;最后 =C-x b= 切回来。

#+end_quote

#+end_quote

** 用名字运行命令:M-x 和 Tab 补全
键盘上的组合有限,命令却是无限的。 *按 M-x,输入命令全名、回车,就能运行任何命令* ------ 命令名不用打全,按 =Tab= 能补全。

比如把光标之后的 "changed" 全部替换成 "altered":

#+begin_example
M-x repl s <Tab> <Return>    ← 自动补全成 replace-string,回车执行
changed <Return>              ← 要被替换的词
altered <Return>               ← 换成的新词
#+end_example

补全不挑对象:命令名、文件名、缓冲区名都行。比如 =C-x b *M<Tab>= 自动补成 =*Messages*=,少打好多字。

再送两个常用命名命令:

- =M-x dired=:文件管理器,列目录、重命名、删除文件都在里面做;
- =M-x list-packages=:浏览并安装社区软件包。

** 状态栏:模式行
窗口底部形如 =-:**-  TUTORIAL  63% L749  (Fundamental)= 的一行就是 *模式行*,从左到右:

| 片段            | 含义                                            |
|-----------------+-------------------------------------------------|
| =-:**-=         | =**= 表示改过还没保存; =--= 表示没改动          |
| =TUTORIAL=      | 当前文件/缓冲区名                               |
| =63%=           | 你在全文中的位置(开头显示 =Top=,结尾显示 =Bot=) |
| =L749=          | 光标所在行号                                    |
| =(Fundamental)= | 当前 *主模式* (下一节)                          |

--------------

** 模式
*主模式(major mode)* 决定 Emacs 怎么理解你的文本。写代码用编程模式,写文章用 Text 模式。任一时刻只有一个主模式生效:

| 按键                            | 作用                            |
|---------------------------------+---------------------------------|
| =M-x text-mode <Return>=        | 切换到 Text 模式,适合写普通文章 |
| =M-x fundamental-mode <Return>= | 切回默认的基础(Fundamental)模式 |
| =C-h m=                         | 查看当前主模式的说明            |

每个主模式下 *大部分按键行为一致,少数会微调* 。比如 Text 模式里 =M-f= 、 =M-b= 会把 =don't= 这样的撇号当成词的一部分,而 Fundamental 模式不会。

*次模式(minor mode)* 是独立小开关,叠在主模式上,随用随开:

| 按键                          | 作用                                             |
|-------------------------------+--------------------------------------------------|
| =M-x auto-fill-mode <Return>= | 开/关 *自动换行* (打字超宽自动折行,再按一次关闭) |
| =C-x f= + 参数                | 设置换行宽度(如 =C-u 70 C-x f= 设为 70 字符)     |
| =M-q=                         | 手动把当前段落重新排版(改了段中内容后常用)       |

#+begin_quote

#+begin_quote
开启自动换行,然后狂打 =asdf = 带空格的词,看它自动折成两行;再把光标放进某段,按 =M-q= 重新排版。

#+end_quote

#+end_quote

** 搜索
Emacs 的搜索是 *边打边搜* 的(叫"增量搜索"):你敲一个字母,光标立刻跳到它出现的地方;再敲一个,继续逼近目标。 *不用先打完整词再回车* 。

| 按键                   | 作用                    |
|------------------------+-------------------------|
| =C-s=                  | 向下搜                  |
| =C-r=                  | 向上搜                  |
| 回车                   | 结束搜索                |
| =C-g=                  | 取消搜索                |
| 再按一次 =C-s= / =C-r= | 跳到下一个 / 上一个匹配 |
| =<DEL>=                | 往回退一步              |

#+begin_quote

#+begin_quote
按 =C-s=,然后 *慢慢* 敲 =cursor= 这几个字母,边敲边看光标怎么跳。再按 =C-s= 找下一个,按几次 =<DEL>= 看后退效果,最后回车结束。

#+end_quote

#+end_quote

没搜到会响铃并提示 "failing",意思是 *当前方向上* 没有更多匹配了,往反方向搜就有。

** 分屏和框架
*窗口* 是把一个 Emacs 画面分割成几块; *框架* 是我们平时说的"一个程序窗口"(现代屏幕上 Emacs 应用整体开出来的一个个窗口)。

| 按键        | 作用                                              |
|-------------+---------------------------------------------------|
| =C-x 2=     | 上下分成两个窗口                                  |
| =C-x o=     | 跳到另一个窗口(*o* = other)                       |
| =C-x 1=     | 只保留当前窗口,其余关闭                           |
| =C-x 4 C-f= | 在下方的窗口里打开一个文件                        |
| =C-M-v=     | 滚动 *另一个* 窗口的内容(光标留在原地,边看边滚动) |
| =C-x 5 2=   | 新建一个框架                                      |
| =C-x 5 0=   | 关闭当前框架                                      |

#+begin_quote
💡 没有 Alt 键时, =C-M-v= 要 *先点一下 ESC,再按 C-v*,三个键一起按不行。

#+end_quote

#+begin_quote
💡 经典用法:上面窗口看资料、下面窗口写代码。手不用挪窝, =C-M-v= 直接滚上面那个窗口。

#+end_quote

#+begin_quote

#+begin_quote
按 =C-x 2= 分屏, =C-M-v= 滚动下面窗口, =C-x o= 切过去再切回来,最后 =C-x 1= 合并。

#+end_quote

#+end_quote

** 帮助
Emacs 的帮助都以 =C-h= 开头, *遇到不懂的键, 当场查*:

| 按键             | 作用                                                   |
|------------------+--------------------------------------------------------|
| =C-h ?=          | 列出所有帮助命令                                       |
| =C-h c <按键>=   | 一句话告诉你这个键是干什么的                           |
| =C-h k <按键>=   | 这个键的完整文档                                       |
| =C-h x= + 命令名 | 查一个命名命令(第 10 节 =M-x= 跑的那种)                |
| =C-h v= + 变量名 | 查一个变量的文档和当前值                               |
| =C-h a= + 关键词 | 列出名字里含这个词的所有命令                           |
| =C-h i=          | 打开内置手册(Info),输 =m emacs <Return>= 读 Emacs 手册 |
| =C-h m=          | 查当前主模式的文档                                     |
| =C-h r=          | 直接读 Emacs 完整手册                                  |

#+begin_quote
💡 若 =C-h= 没反应,改按 =F1=,或输入 =M-x help <Return>= 。

#+end_quote

#+begin_quote

#+begin_quote
按 =C-h k C-f=,看看 =C-f= 的文档长什么样,看完 =C-x 1= 关掉。

#+end_quote

#+end_quote

** 挂起, 退出与脱困

| =C-z=               | *临时* 挂起 Emacs(终端里用;回 shell 输 =fg= 或 =%emacs= 召回) |

#+end_quote
