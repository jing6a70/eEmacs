# Emacs 基础操作

> 键标注约定：
> - `C-x` = Ctrl+x，`M-x` = Alt+x（Meta 键）
> - `RET` = 回车，`SPC` = 空格
> - "point" = 光标位置，"region" = 被选中的文本

---

## 1. 文件 / 缓冲区

| 键 | 操作 |
|---|---|
| `C-x C-f` | 打开文件（输入路径，支持 Vertico 补全） |
| `C-x C-s` | 保存当前缓冲区 |
| `C-x s` | 保存所有修改过的缓冲区（会逐个询问） |
| `C-x b` | 切换缓冲区（Vertico 列表，模糊搜索） |
| `C-x k` | 关闭当前缓冲区 |
| `C-x d` | 打开 Dired 文件浏览 |
| `C-x C-c` | 退出 Emacs |

## 2. 光标移动

| 键 | 操作 |
|---|---|
| `C-f` / `C-b` | 前 / 后 移一个字符 |
| `C-n` / `C-p` | 下 / 上 移一行 |
| `C-a` / `C-e` | 行首 / 行尾 |
| `M-<` / `M->` | 缓冲区开头 / 结尾 |
| `C-v` / `M-v` | 向下 / 向上 翻页 |
| `C-l` | 把当前行移到屏幕中间 |
| `M-g g` | 跳到指定行（consult） |
| `M-g i` | 跳到本文件的函数/变量（consult-imenu） |

## 3. 选择 / 拷贝 / 粘贴

| 键 | 操作 |
|---|---|
| `C-SPC` | 开始/结束选区（标记 point） |
| `M-h` | 选一整段 |
| `C-x h` | 全选 |
| `M-w` | 复制选区 |
| `C-w` | 剪切选区 |
| `C-y` | 粘贴（yank） |
| `M-y` | 上翻粘贴历史（剪贴板） |
| `C-/` 或 `C-_` | 撤销 |
| `C-x u` | 可视化撤销树（undo-tree） |
| `C-x C-u`... | 常用前缀键：可撤销一次 = `C-/` 重复按 |

## 4. 搜索 / 替换

| 键 | 操作 |
|---|---|
| `C-s` | incremental search（本项目重绑为 `consult-line`，全文行搜索） |
| `C-r` | incremental search 反方向 |
| `M-s r` | consult-ripgrep 项目全文搜索（需要 ripgrep） |
| `M-%` | 交互式替换（replace-string 的确认版） |
| `C-M-%` | 正则替换 |

## 5. 窗口

| 键 | 操作 |
|---|---|
| `C-x 1` | 当前窗口独占 |
| `C-x 2` | 上下分屏 |
| `C-x 3` | 左右分屏 |
| `C-x o` | 切到下一个窗口 |
| `C-x 0` | 关闭当前窗口 |
| `M-0` | 跳到 Treemacs 窗口 |

## 6. minibuffer 操作（Vertico）

将鼠标放到 minibuffer（提示栏）时可用：

| 键 | 操作 |
|---|---|
| `TAB` | 打开候选栏 |
| `RET` | 确认 |
| `M-<` / `M->` | 首尾候选 |
| `DEL` | 回到上一级目录 |
| `M-r` | 查询历史 |

## 7. 帮助系统

| 键 | 操作 |
|---|---|
| `C-h f` | 查看函数文档| `C-h v` | 查看变量含义 |
| `C-h k` | 按键按下后显示对应函数（查键位用最多） |
| `C-h m` | 查看当前 major-mode 的按键说明 |
| `C-h C-h` | 帮助帮助 |

## 8. 模式

本配置关闭菜单栏 / 工具栏 / 滚动条，对应命令：

| 命令 | 操作 |
|---|---|
| `M-x menu-bar-mode` | 开/关菜单栏 |
| `M-x tool-bar-mode` | 工具栏 |
| `M-x display-time-mode` | 显示时间 |

---

**建议的初学者顺序**：先记住 1-3 节（10 次启动就是熟练），然后 5-6 节（窗口/minibuffer），第 4 节按需要再并且常用。
