# 多行编辑

## 概览

三个配合的懒加载包：

| 包 | 用途 |
|---|---|
| `multiple-cursors` | 编辑 N 行同时同步 |
| `iedit` | 编辑所有出现的相同单词 (renaming) |
| `expand-region` | 递归扩大选择: 词 → 符号 → 行 → 函数 |

三者都可防御性打开 — 你只是什么时候需要他们。

---

## multiple-cursors

| 键 | 操作 |
|---|---|
| `C-c m a` | 在**每一行**上放一个光标（在活动区域内；区域=线范围） |
| `C->` | 跳到下一个具有相同文本的行 |
| `C-<` | 与相同，反向（向后行） |
| `C-c C->` | 为整缓冲中的**每个出现的相同单词**放一个光标 |
| `C-S-<mouse-1>` | 点击光标在任何地方（多个光标模式） |
| `C-g` | 结束多光标会话 |

### 用法提示

- 首先开始选择区域（例如 `C-=` 或 `M-h`），然后 `C-c m a`。
- 相同的文本通过点击出现在相同的行 — 只需 `C-S-<mouse-1>` 任意触发。
- 可以同时所有光标合并：重复使用 `C->` 在相同的行间隙。
- 输入文本或按 TAB 将所有行一次性编辑。

## iedit

| 键 | 操作 |
|---|---|
| `C-c e` | 开始 iedit 模式：从点处的单词开始，相同的词在全部 buffer 高亮（可编辑） |
| `RET` / `C-g` | 结束 iedit 模式，返回到正常编辑状态 |

### 为什么 iedit 有用

- 在单个文件内**重命名**一个词 (e.g. `itemID` → `equipLoopCount`)，无需正则。
- 如果代码源且 LSP online，则用 `M-x lsp-rename`(语义性重命名)。
- iedit 不重命名 **LSP 语义** — 它通过定义以**纯文本**相同字符串匹配。

## expand-region

| 键 | 操作 |
|---|---|
| `C-=` | 递归扩大区域：词 → 符号 → 行 → 表达式 → 函数 |
| `C-- C-=` (`C--` prefix = contract) | 复合选择 |

### 工作流

1. 在任意一个词上，`C-=`。
2. 按 `C-=` 重复多次，直到选择所需大小。
3. 现在在这个区域上你可以：运行 magit 块 `C-c e`（iedit），或复制，或替换为新文本。

## 全景工作流 (三合一)

1. 打开文件，按 `C-=`直到区域包含整个名称。
2. 用 `C-c e` 使用 iedit 重命名所有出现。
3. 按 `C-g` 停止 iedit 模式，检查结果。

---

## 键位冲突说明

- `C->` / `C-<` 在普通 Emacs 没什么成本。
- `C-c e` (`iedit`) 可能有其他 `C-c e` 绑定的极大冲突项风险。
